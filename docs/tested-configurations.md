# Tested configurations and media samples (release 0.1.0)

What release 0.1.0 has actually been run on, with what files, and what has **not** been tested. Every result here comes from an automated run on GitHub Actions; links to the runs are in [the Milestone 10 report](reports/milestone-10.md#3-verification). Nothing in this list has been run by hand on a physical PC, phone or TV except where it says so.

## Machines

| Configuration | Used for | Notes |
|---|---|---|
| GitHub Actions `windows-latest` (Windows Server 2025, x64, 4 cores, 16 GB) | App build, launch smoke test, visual review (1920 × 1080 at 100 %), install/upgrade/uninstall test, soak test, engine tests with the pinned libmpv | No GPU: Microsoft Basic Render Driver (WARP), so the video path is ANGLE on a software Direct3D device and decoding is software. No sound device, so playback reports "Audio: Off". One display |
| GitHub Actions `ubuntu-latest` (x64) | Platform-neutral tests (core, data, library, YouTube, media server) and engine tests against Ubuntu's libmpv | Not the shipped libmpv; checks the binding, not the Windows build |
| ARM64 | Build and packaging only (cross-compiled on x64) | **The ARM64 build has never been started.** GitHub's ARM64 Windows runners were not used |
| adi's own PC | Milestone 8 casting to their TV ("we are golden") | Other milestones' features have not been confirmed on it |

### App files (`tools/visual-review/make-test-media.sh`)

Used by the visual review (77 states driven through UI Automation) and the install and soak tests: 1 to 20 minute H.264/AAC clips in MP4, "Night Market.mkv" with two embedded subtitle tracks and a separate `.srt`, a library of films (including two quality copies and a `Sample` clip that must be ignored), a show with three episodes sharing an intro and credits, personal videos, a lossless FFV1 file, a damaged copy and a subtitles-only file.

### Long, high-bitrate file (Release workflow)

"Soak 1080p60.mkv": 1920×1080 at 60 frames a second, H.264 at about 20 Mbit/s, AC-3 5.1 at 448 kbit/s, 130 minutes (about 20 GB), built by repeating a 5-minute encoded segment without re-encoding. Played for two hours by `tools/packaging/Test-Soak.ps1` after 50 open/close cycles.

## Areas, and how far each was tested

| Area | Tested | Not tested |
|---|---|---|
| Clean install, upgrade, uninstall | Silent install of a stand-in 0.0.9, upgrade to 0.1.0 while the app and media server run, launch, uninstall; files, Start menu, uninstall entry, Open with, data kept (`Test-Install.ps1`) | The interactive "remove my data" answer (Yes) on uninstall; SmartScreen on a consumer PC; ARM64 install |
| Database migrations | Every earlier schema version (1 to 5) upgrades to the current one with data kept and a backup made (`UpgradePathTests`) | Real long-used databases from adi's PC |
| Codecs and containers | The engine files above | E-AC-3, DTS, TrueHD, Dolby Vision, VC-1, real camera files, very large real-world MKVs |
| Large, high-bitrate files | 20 Mbit/s 1080p60, 20 GB, two hours | 4K, 80+ Mbit/s remuxes, network shares |
| HDR | — | **Not supported**: HDR10/HLG play tone-mapped to SDR through the ANGLE path; no HDR output |
| Hardware decoding | — | CI has no GPU, so only software decoding ran. libmpv's `auto-safe` hardware decoding (D3D11VA) is enabled but unverified |
| Subtitles and sync | SRT, ASS, MP4 text, sidecar and `Subs` folder discovery, offsets (unit and engine tests, visual review) | PGS/VobSub picture subtitles, right-to-left scripts |
| Audio-track switching | multi-track.mkv in engine tests and visual review | Real output devices (CI has none), passthrough |
| Full screen, multiple monitors | Full screen and mini player on one display (visual review); display-change logic by unit tests | **Multiple physical monitors** |
| DPI and resizing | 100 % at 1920×1080, window resize and minimum size (visual review) | **125 %, 150 %, 200 %** scaling |
| Keyboard and accessibility | Every shortcut through the shortcut tests; the visual review drives the app by UI Automation names; contrast ratios measured | **Narrator** end to end, high-contrast themes on a real PC |
| Playback persistence | Resume, per-file and per-show choices (unit tests, visual review, install test) | |
| Library rescans | Scanning, cancel, rescan, duplicate grouping (Media tests, visual review) | Libraries of thousands of files |
| Remote authentication | Sign-in, lock-out, sessions, cross-site, file access (61 server tests) | **A real phone** (owed by adi since Milestone 7) |
| Network interruptions | Server tests for withdrawn access and dropped conversions; casting tests for a TV that disappears | A real Wi-Fi drop |
| Invalid or missing files | Missing, empty, damaged, truncated, not a video, broken subtitles | |
| CPU, GPU, memory over time | Soak test (10 min in CI, 2 h in the Release workflow), results in the Milestone 10 report | GPU use (no GPU in CI) |
| YouTube | API and sign-in logic with recorded responses (35 tests) | Playback on adi's PC (YouTube refused CI's embed with error 150) |
